# 🌱 GreenEye – AI Anti-Littering Surveillance System

An AI-powered campus surveillance project designed to detect littering activities, capture evidence and manage violations through a web-based dashboard.

## 📌 Overview

GreenEye aims to promote a cleaner campus environment by using Artificial Intelligence and computer vision to identify littering activities.

The system is designed to detect violations, store evidence images, identify registered students and manage penalty records.

## ✨ Key Features

- 🤖 AI-based littering detection
- 📸 Evidence image capture and storage
- 👤 Student identification using face recognition
- 📋 Violation management dashboard
- 💰 Fine management and payment status tracking
- 📊 Violation monitoring and review

## ⚙️ How It Works

1. Camera footage is processed by the AI detection service.
2. The system identifies potential littering activities.
3. Evidence images are stored for review.
4. Student identification is performed using face recognition.
5. Violations are managed through the dashboard.
6. Fine records and payment statuses are maintained.

## 📊 Violation Management

The planned system supports these statuses:

- Pending Review
- Approved
- Rejected
- Paid

## 🎯 Project Objective

To encourage responsible waste disposal and maintain a cleaner campus through AI-powered monitoring and digital violation management.
