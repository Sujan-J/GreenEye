# GreenEye – Anti-Littering AI Surveillance System

College project starter built around the project documents: HTML/CSS/JavaScript frontend, Node.js/Express backend, MongoDB database, and later YOLOv8 + face recognition + email + UPI QR modules.

## Day 1 setup
1. Install Node.js LTS and MongoDB Community Server, or use MongoDB Atlas.
2. Copy `backend/.env.example` to `backend/.env` and set `MONGODB_URI`.
3. Open a terminal in `backend`.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open http://localhost:5000
